# Python Arcade Fighting Game

## About the Project

A 2D arcade fighting game developed in Python, inspired by platform fighting games such as Brawlhalla.

Players compete in fast-paced battles in an arcade-style environment, using movement, attacks, and different abilities to defeat their opponents.

The goal is to create an entertaining local multiplayer experience with simple controls and exciting gameplay.

## Features

- 2D platform fighting gameplay
- Arcade-style combat
- Player movement and jumping
- Attack and defense mechanics
- Local multiplayer gameplay
- Interactive arena and platforms

## Technologies Used

- Python
- Pygame
